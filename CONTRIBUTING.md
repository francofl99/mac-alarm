# Contribuir

Issues y PRs bienvenidos.

- Compilá con `./build.sh` y probá la app antes de abrir el PR.
- Un cambio por PR, con una descripción de qué comportamiento cambia.
- Estilo: Swift estándar, sin comentarios que repitan lo que el código ya dice.
- Si tocás el event tap o el bloqueo de teclado, aclará cómo lo probaste: es la parte que puede
  dejar a alguien sin teclado.
